# Tycho ReaPack Repository

ReaPack index for Tycho REAPER scripts.

Import URL:

```text
https://raw.githubusercontent.com/tychomusic/reapack/main/index.xml
```

## Packages

- **Track Navigator** - standalone ReaImGui NAV track visibility manager for REAPER.
- **Reflex** - ReaImGui track inspector, visibility manager, routing view, FX chain tool, send topology view, and Remote macro pad for REAPER. Requires ReaImGui 0.10+ and SWS Extension; the FX Window Toggle action also requires js_ReaScriptAPI.
